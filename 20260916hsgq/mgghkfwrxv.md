# 【关注】运动后的肌肉酸痛正常吗

> 更新时间：2026-09-16 (UTC+8)

**媒体：家庭用药   专家：孙业青（骨科）**

**运动健身，可引起酸痛******

一般来说，运动或健身锻炼后的肌肉酸痛，是由于训练过程中人体产生大量的乳酸堆积在肌肉中，进而使人产生酸痛的感觉。同时，由于乳酸等物质的积聚，使肌肉内的渗透压增大，促使肌肉组织内吸收较多的水分而产生局部肿胀，也会产生酸胀的感觉。但这种由于运动产生的乳酸属于正常现象。

在不继续运动的情况下，肌肉酸痛在3～5天后一般就会自动消失。如果对酸痛部位进行静态牵拉练习，做些舒缓的牵拉活动，适当地拍打按摩，进行热敷按摩等均有助于缓解肌肉痉挛及肌肉酸痛。

**出现酸痛，宜暂停锻炼******

当锻炼后出现全身酸痛，特别是已锻炼过的部位，建议练习者停止对酸痛部位的再次练习，这样可以给已经锻炼过的肌肉一个休息时间。此时，可以选择其他部位的肌肉进行锻炼，或对酸痛部位做些舒缓的活动，不宜继续盲目锻炼，否则可加重肌肉酸痛甚至引起肌肉拉伤。而运动导致的肌肉拉伤往往也表现为肌肉酸痛，甚至影响关节活动，但从根本上来说，拉伤引起的酸痛与普通的酸痛有本质的区别。拉伤会造成肌肉的病理性改变，如细胞变性、细胞坏死等，肌肉或韧带可能会发生撕裂，这样不但会出现酸痛的情况，影响继续运动或训练，还可能会带来较严重的后果。

**肌肉酸痛和拉伤酸痛鉴别******

一般说来，肌肉和韧带拉伤往往会因一个损伤性动作而突然出现，一般是突然用力或完成某一个动作后出现肌肉或韧带区域疼痛，而肌肉酸痛则是逐渐加重的。可以通过以下几个办法来鉴别这些疼痛。

**1**

**牵　拉**

肌肉酸痛通过牵拉能得到缓解，而如果是肌肉拉伤或韧带损伤的话，牵拉反而会使疼痛加重。

**2**

**局部检查**

可通过按压酸痛肌肉进行判断。一般来说，普通肌肉酸痛往往是整个肌肉的按压酸痛，疼痛不会太剧烈；但如果按压肌肉后，酸痛的部位集中在肌肉或肌腱的某点或小块区域，患者常常有剧烈的疼痛，则肌肉或肌腱损伤的可能性更大，如果是大范围拉伤也会引起整个肌肉部位的按压酸痛。

肌肉酸痛可以通过休息、牵拉、按摩等得到缓解，而**肌肉韧带损伤应该早期诊断并进行治疗，否则会造成病情加重甚至肢体的功能障碍。**如果自己不能鉴别或症状持续不见好转，要及时找专科医生帮忙诊断治疗。

**如何正确锻炼******

首先，要避免过度运动。很多人平时很少运动，偶尔运动一次，便要完全透支自己的体力，直到觉得“过瘾”才停止运动，所以在运动后的第二天难免会出现腰酸腿疼。而体力透支时，肌肉控制力会减弱，动作容易变形，如果此时肌肉突然受到剧烈的牵拉，则容易导致肌肉、肌腱的拉伤。所以平时运动较少的人在运动时要适可而止。

其次，运动后的放松非常重要，尤其是配合活动部位的牵拉，可以促进血液循环，有助于减缓甚至避免肌肉酸痛的发生。运动贵在长期坚持，且要有规律性，这样不仅能锻炼身体，还可以提高身体耐受性，减少肌肉酸痛及肌肉韧带损伤的发生。
